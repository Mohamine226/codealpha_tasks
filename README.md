## 📌 Task 1: Event System (Django)
- **Description**: A web application to create events, manage registrations, and display participants.
- **Technologies**: Django, Bootstrap, SQLite
- **Folder**: `Task1_EventSystem/`
- **Usage**:
  1. Navigate to the `Task1_EventSystem` folder.
  2. Create a virtual environment and install dependencies:
     ```bash
     pip install -r requirements.txt
     ```
  3. Run the server:
     ```bash
     python manage.py runserver
     ```
  4. Access the pages:
     - `/add-event/` → Add an event  
     - `/register-event/` → Register for an event  
     - `/registrations/` → View registrations  
     - `/admin/` → Admin interface (after creating a superuser)

## 📌 Task 2: URL Shortener (Python)
- **Description**: A tool to shorten URLs and manage them easily.

- **Usage**:
